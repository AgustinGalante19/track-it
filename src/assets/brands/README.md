# Bundled brand SVGs

YouTube, Spotify and Netflix SVGs are vendored from the official
[Simple Icons repository](https://github.com/simple-icons/simple-icons/tree/develop/icons)
(retrieved 2026-10-14). See `sources.json` for each brand's upstream source and
guidelines. The upstream catalog contains no separate icon-specific license
entry for these three assets at retrieval time.

The repository's CC0 dedication and disclaimer are included alongside the assets.
Brand trademarks remain with their owners. These icons identify user-entered
subscriptions and do not imply endorsement. Disney+ and Prime Video use a generic
entertainment icon in this release.

SVG files are imported by Vite and bundled locally; no runtime CDN is used.
